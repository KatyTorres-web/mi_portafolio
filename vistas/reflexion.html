Mirar hacia atrás también es aprender

Reflexión metacognitiva

Durante el curso fortalecí mis conocimientos sobre la creación de interfaces, la organización del código y el desarrollo de aplicaciones interactivas. Cada práctica me permitió reconocer mis avances, identificar dificultades y descubrir qué aspectos necesito seguir mejorando.

SEMANA 01

Fundamentos de la Web y configuración del entorno

¿Qué aprendí? Aprendí los conceptos fundamentales del desarrollo web y las diferencias entre una página web, un sitio web, una aplicación web y un sistema web. También comprendí de manera general cómo funciona la comunicación entre el navegador y el servidor mediante HTTP y HTTPS. Además, conocí las herramientas principales de Visual Studio Code y la utilidad de GitHub para organizar y compartir proyectos.

¿Cómo aprendí? Mediante la revisión de conceptos, la exploración del entorno de desarrollo y el reconocimiento de las herramientas necesarias para comenzar a programar. La práctica me permitió familiarizarme con el editor de código, sus extensiones y la organización de archivos de un proyecto web.

¿Qué necesito reforzar? Necesito seguir practicando Git y GitHub, especialmente la gestión de cambios y la organización de repositorios. También quiero profundizar en el funcionamiento de los protocolos web para comprender mejor la comunicación entre el cliente y el servidor.

SEMANA 02

HTML5, CSS3 y diseño responsivo

¿Qué aprendí? Aprendí a comprender la estructura de una página web mediante HTML5 y la función de CSS en la presentación visual del contenido. Reforcé el uso de elementos semánticos y conocí técnicas de distribución como Flexbox y CSS Grid. También comprendí la importancia del diseño responsivo, los metadatos, la accesibilidad y la optimización básica para motores de búsqueda.

¿Cómo aprendí? Mediante ejercicios de estructuración y maquetación, la revisión de propiedades CSS y el análisis de diferentes formas de distribuir los elementos de una interfaz. La comparación de diseños y el estudio de unidades relativas me ayudaron a comprender cómo adaptar una página a diferentes tamaños de pantalla.

¿Qué necesito reforzar? Necesito mejorar mi capacidad para combinar Flexbox y Grid en diseños más complejos. También debo prestar mayor atención a la accesibilidad, la validación del código y las pruebas en distintos dispositivos y navegadores.

SEMANA 03

Frameworks CSS: Bootstrap y Tailwind CSS

¿Qué aprendí? Aprendí que los frameworks CSS facilitan la construcción de interfaces mediante componentes reutilizables y clases de utilidad. Comprendí las diferencias entre Bootstrap, que proporciona componentes y estructuras predefinidas, y Tailwind CSS, que permite aplicar estilos mediante clases específicas. También reforcé la creación de barras de navegación, tarjetas y layouts responsivos.

¿Cómo aprendí? Mediante las prácticas de maquetación y la reproducción de interfaces de referencia. Los ejercicios de las prácticas calificadas me permitieron analizar la distribución de los elementos, aplicar estilos y comprender la importancia de mantener una presentación coherente en diferentes tamaños de pantalla.

¿Qué necesito reforzar? Necesito desarrollar mayor criterio para elegir entre CSS tradicional, Bootstrap y Tailwind CSS según las necesidades del proyecto. También quiero mejorar la organización de las clases y evitar estilos innecesarios que dificulten el mantenimiento del código.

SEMANA 04

JavaScript, DOM y animaciones

¿Qué aprendí? Aprendí que JavaScript permite agregar interactividad a las páginas web mediante eventos y modificaciones del DOM. También estudié el uso de funciones flecha, funciones autoinvocadas (IIFE) y closures. Asimismo, conocí la utilidad de Canvas API y requestAnimationFrame() para desarrollar animaciones y actualizar elementos gráficos.

¿Cómo aprendí? Mediante el análisis de ejemplos de código y la práctica de funcionalidades interactivas. El trabajo relacionado con el proyecto Catch Ball me permitió relacionar los conceptos de JavaScript con la lógica de una experiencia dinámica, mientras que la revisión de eventos y funciones me ayudó a comprender cómo organizar el comportamiento de una página.

¿Qué necesito reforzar? Necesito practicar más la manipulación del DOM, el manejo de eventos y la organización de funciones. También quiero profundizar en el funcionamiento de las animaciones para comprender mejor su ciclo de ejecución y evitar actualizaciones innecesarias.

SEMANA 05

React, JSX y componentes

¿Qué aprendí? Aprendí los fundamentos de React como biblioteca para construir interfaces mediante componentes reutilizables. Comprendí la función de Vite en la configuración del entorno, el uso de JSX para describir interfaces y la transmisión de datos mediante props. También estudié children, la composición de componentes y las estrategias de estilado para organizar una aplicación de página única (SPA).

¿Cómo aprendí? Mediante la configuración y organización de un proyecto React, la revisión de componentes y los ejercicios de transmisión de datos entre componentes. El desarrollo de la práctica practica_semana5_DAW me permitió relacionar la arquitectura de componentes con la construcción de una interfaz.

¿Qué necesito reforzar? Necesito mejorar la separación de responsabilidades entre componentes y practicar la transmisión de datos para evitar estructuras difíciles de mantener. También quiero profundizar en el funcionamiento del renderizado de React y en la aplicación de estilos organizados y reutilizables.

SEMANA 06

React, eventos, formularios, routing y APIs

¿Qué aprendí? Aprendí a relacionar los eventos con las acciones del usuario y a comprender el renderizado condicional e iterativo en React. También estudié el manejo del estado con useState, la navegación mediante React Router y el consumo de información desde APIs utilizando Axios y async/await. Comprendí la importancia de gestionar los estados de carga, los datos recibidos y los posibles errores durante una solicitud.

¿Cómo aprendí? Mediante el análisis de la estructura de una aplicación React y los ejercicios orientados a la navegación, los formularios y la obtención de información externa. La práctica Practica-semana-6_misk-i-bitter me permitió relacionar los conceptos estudiados con la organización de páginas, componentes y servicios de una aplicación frontend.

¿Qué necesito reforzar? Necesito practicar el manejo de errores en las solicitudes a APIs, la validación de formularios y la actualización del estado. También quiero mejorar la organización de las rutas y comprender mejor cómo gestionar los datos para que la interfaz responda correctamente ante diferentes situaciones.

CIERRE DEL CURSO

Reflexión final del curso

¿Qué aprendí? Durante el curso comprendí progresivamente las principales etapas del desarrollo frontend, desde la estructura de una página con HTML hasta la creación de interfaces interactivas con JavaScript y aplicaciones organizadas mediante React. Aprendí a utilizar herramientas de desarrollo, aplicar estilos responsivos, organizar componentes, gestionar eventos y comprender los fundamentos de la navegación y el consumo de APIs. Además, reconocí que un proyecto web no consiste únicamente en presentar información: también requiere organizar el código, facilitar la interacción y considerar la accesibilidad, el mantenimiento y la experiencia de uso.

¿Cómo aprendí? Mediante las clases, las guías de práctica, los ejercicios de laboratorio y la revisión de proyectos en GitHub. La elaboración de diferentes interfaces me permitió relacionar la teoría con la práctica y comprender que cada tecnología cumple una función dentro del desarrollo web. Asimismo, la revisión de errores y la búsqueda de soluciones fortalecieron mi capacidad para analizar problemas, probar alternativas y mejorar progresivamente mi trabajo.

¿Cómo aplicaré lo aprendido? Aplicaré estos conocimientos en futuros proyectos académicos y profesionales, especialmente en aplicaciones que permitan organizar información y facilitar procesos. Un ejemplo relacionado con mi experiencia es el sistema de gestión de expedientes desarrollado para la Municipalidad Distrital de Sapallanga, cuyo propósito es digitalizar el registro manual y facilitar la trazabilidad y derivación de los expedientes. Continuaré fortaleciendo mis habilidades en React, JavaScript, diseño responsivo y consumo de APIs para desarrollar aplicaciones comprensibles, mantenibles y útiles para las personas.

Compromiso de mejora personal: Reconozco que aprender desarrollo web requiere práctica constante, curiosidad y disposición para corregir errores. Continuaré documentando mis avances, revisando la calidad de mi código y utilizando la retroalimentación para identificar oportunidades de mejora. Considero que aprender de manera autónoma y evaluar mi propio progreso será fundamental para seguir creciendo como estudiante de Ingeniería de Sistemas.
