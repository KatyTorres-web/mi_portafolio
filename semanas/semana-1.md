# Semana 1 — Fundamentos de la Web y configuración del entorno

Repositorio relacionado: [portafolio-web-uncp](https://github.com/KatyTorres-web/portafolio-web-uncp).

La primera práctica aborda la arquitectura y el funcionamiento de la Web, los tipos de soluciones web y la configuración inicial de Visual Studio Code.

**Fecha o tema principal:** Fundamentos de la Web y configuración del entorno de desarrollo.

## Temas aprendidos

### Tema 1: Fundamentos y funcionamiento de la Web

**Definición con mis palabras:** La Web permite acceder a documentos, servicios y aplicaciones a través de Internet. Para comprender su funcionamiento, es necesario conocer cómo se localizan los servidores y cómo se intercambia información entre el cliente y el servidor.

**Procedimiento:**

1. Diferencié los conceptos de página web, sitio web, aplicación web y sistema web.
2. Revisé el funcionamiento de DNS, TCP/IP y los protocolos HTTP/HTTPS.
3. Identifiqué la función del frontend, backend y desarrollo fullstack.

**Conceptos clave:** Página web, sitio web, aplicación web, sistema web, DNS, HTTP, HTTPS, frontend y backend.

### Tema 2: Configuración del entorno de desarrollo

**Definición con mis palabras:** Un entorno de desarrollo reúne las herramientas necesarias para escribir, organizar, ejecutar y revisar el código de una aplicación.

**Procedimiento:**

1. Abrí el proyecto desde Visual Studio Code.
2. Exploré el editor, el explorador de archivos, la terminal integrada y el control de versiones.
3. Revisé extensiones útiles para desarrollar y visualizar páginas web.

**Conceptos clave:** Visual Studio Code, editor de código, terminal, extensiones, Live Server y Git.

## Ejercicios de laboratorio y resultados

### Ejercicio 1: Reconocimiento del entorno de desarrollo

**Objetivo:** Identificar las herramientas básicas para iniciar un proyecto web.

**Procedimiento:** Exploré la interfaz de Visual Studio Code, reconocí sus paneles principales y revisé las extensiones que facilitan la edición y ejecución del código.

**Resultado:** Reconocí los componentes del entorno de desarrollo y su utilidad para organizar los archivos de un proyecto web.

### Ejercicio 2: Proyecto inicial en GitHub

**Objetivo:** Organizar y registrar el trabajo académico en un repositorio.

**Procedimiento:** Utilicé el repositorio [portafolio-web-uncp](https://github.com/KatyTorres-web/portafolio-web-uncp) como referencia del trabajo de la práctica y del registro del proyecto.

**Resultado:** Conté con un repositorio para identificar y documentar el trabajo académico desarrollado.

## Reflexión semanal

- **¿Qué aprendí?** Aprendí a diferenciar los principales tipos de soluciones web y a comprender el proceso básico de comunicación entre un navegador y un servidor.
- **¿Cómo aprendí?** Mediante la revisión de conceptos, la exploración de Visual Studio Code y las actividades iniciales de configuración del entorno.
- **¿Qué necesito reforzar?** Necesito profundizar en el funcionamiento de los protocolos web y mejorar mi manejo de Git y GitHub para organizar los cambios de mis proyectos.
