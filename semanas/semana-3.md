# Semana 3 — Frameworks CSS: Bootstrap y Tailwind

Repositorios relacionados: [practica_calificada-semana-3](https://github.com/KatyTorres-web/practica_calificada-semana-3) y [practica-2](https://github.com/KatyTorres-web/practica-2).

La práctica sobre frameworks CSS se centra en Bootstrap 5 y Tailwind CSS, la creación de componentes de interfaz y la adaptación responsiva de diseños.

**Fecha o tema principal:** Frameworks CSS modernos: Bootstrap 5 y Tailwind CSS.

## Temas aprendidos

### Tema 1: Frameworks CSS

**Definición con mis palabras:** Los frameworks CSS proporcionan componentes, utilidades y convenciones que facilitan el diseño de interfaces web y permiten desarrollar con mayor rapidez.

**Procedimiento:**

1. Revisé la incorporación de Bootstrap y Tailwind CSS a un documento HTML.
2. Identifiqué las diferencias entre el uso de componentes predefinidos y las clases de utilidad.
3. Analicé cómo ambos enfoques ayudan a construir interfaces con estilos consistentes.

**Conceptos clave:** Bootstrap 5, Tailwind CSS, CDN, componentes, clases de utilidad y estilos.

### Tema 2: Componentes y layouts responsivos

**Definición con mis palabras:** Los componentes de interfaz son elementos visuales reutilizables, como tarjetas, botones, formularios y barras de navegación. Los layouts responsivos permiten distribuirlos según el espacio disponible.

**Procedimiento:**

1. Revisé la construcción de una barra de navegación adaptable.
2. Analicé la organización de tarjetas, formularios y otros componentes.
3. Consideré el uso de Grid, Flexbox y utilidades de espaciado para adaptar la interfaz.

**Conceptos clave:** Navbar, cards, badges, formularios, Grid, Flexbox y diseño responsivo.

## Ejercicios de laboratorio y resultados

### Ejercicio 1: Desarrollo de interfaces con frameworks CSS

**Objetivo:** Construir una interfaz web utilizando herramientas que faciliten la maquetación y el diseño.

**Procedimiento:** Trabajé con la estructura HTML y revisé la integración de frameworks CSS para construir componentes y aplicar estilos.

**Resultado:** Reforcé el uso de herramientas de maquetación y comprendí cómo organizar una interfaz mediante componentes y utilidades.

### Ejercicio 2: Práctica calificada 2

**Objetivo:** Reproducir interfaces de referencia utilizando HTML y Tailwind CSS.

**Procedimiento:** La práctica contempla listas de mensajes, tarjetas informativas y distribución responsiva de elementos en diferentes columnas y secciones.

**Resultado:** La actividad permitió aplicar conceptos de maquetación, distribución de elementos y adaptación del diseño.

## Reflexión semanal

- **¿Qué aprendí?** Aprendí las diferencias entre Bootstrap y Tailwind CSS y cómo pueden utilizarse para construir interfaces web con componentes y estilos reutilizables.
- **¿Cómo aprendí?** Mediante la revisión de ejemplos, la aplicación de clases CSS y el desarrollo de ejercicios de maquetación.
- **¿Qué necesito reforzar?** Necesito mejorar la selección de clases y componentes, evitar estilos innecesarios y comprobar que los diseños mantengan su organización en dispositivos móviles.
