# Semana 5 — Introducción a React, JSX y componentes

Repositorio relacionado: [practica_semana5_DAW](https://github.com/KatyTorres-web/practica_semana5_DAW).

La guía de esta semana se enfoca en React, Vite, JSX, componentes, props, children y estrategias de estilado para aplicaciones de página única.

**Fecha o tema principal:** React, JSX, componentes y desarrollo de aplicaciones SPA.

## Temas aprendidos

### Tema 1: React y configuración del proyecto

**Definición con mis palabras:** React es una biblioteca de JavaScript que permite construir interfaces de usuario mediante componentes reutilizables. Vite facilita la configuración del proyecto y ofrece herramientas para ejecutar y desarrollar la aplicación.

**Procedimiento:**

1. Revisé la creación de un proyecto con Vite y la selección de React con JavaScript.
2. Analicé la estructura de carpetas y la instalación de dependencias mediante npm.
3. Revisé la función del componente principal `App.jsx` y la ejecución del servidor de desarrollo.

**Conceptos clave:** React, Vite, Node.js, npm, SPA, JSX y componentes.

### Tema 2: JSX, props y children

**Definición con mis palabras:** JSX permite describir la interfaz con una sintaxis similar a HTML dentro de JavaScript. Las props transmiten datos a los componentes, mientras que children permite incluir contenido dentro de un componente.

**Procedimiento:**

1. Revisé la creación y organización de componentes.
2. Analicé cómo transmitir datos desde un componente padre hacia sus componentes hijos.
3. Revisé el uso de children y la aplicación de estilos mediante CSS Modules u otras estrategias.

**Conceptos clave:** JSX, componentes funcionales, props, children, composición y Client-Side Rendering (CSR).

## Ejercicios de laboratorio y resultados

### Ejercicio 1: Creación de una aplicación con React y Vite

**Objetivo:** Configurar una aplicación frontend y organizar su estructura mediante componentes.

**Procedimiento:** Revisé la inicialización del proyecto, la instalación de dependencias y la organización del código en componentes reutilizables.

**Resultado:** Se trabajó con una estructura de aplicación React y se estudiaron las responsabilidades del componente principal y sus componentes hijos.

### Ejercicio 2: Transmisión de datos entre componentes

**Objetivo:** Comprender cómo compartir información entre los elementos que componen una interfaz.

**Procedimiento:** Analicé el uso de props para enviar datos y children para componer el contenido de los componentes.

**Resultado:** Reforcé la organización modular de las interfaces y el flujo de información entre componentes.

## Reflexión semanal

- **¿Qué aprendí?** Aprendí que React permite organizar una interfaz en componentes reutilizables y que Vite simplifica la configuración del entorno de desarrollo.
- **¿Cómo aprendí?** Mediante la creación de la estructura del proyecto, la revisión de componentes JSX y los ejercicios de transmisión de datos.
- **¿Qué necesito reforzar?** Necesito practicar la composición de componentes, el paso de props y la separación de estilos para desarrollar aplicaciones más organizadas y fáciles de mantener.
