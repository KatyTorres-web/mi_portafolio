# Semana 2 — HTML5, CSS3 y diseño responsivo

Práctica relacionada: estructura semántica, maquetación y adaptación a diferentes pantallas.

La guía de esta semana propone implementar HTML semántico, atributos ARIA, CSS Grid, Flexbox, tipografía fluida, diseño responsivo y validaciones de accesibilidad y SEO.

**Fecha o tema principal:** HTML5, CSS3, Flexbox, Grid, diseño responsivo y SEO.

## Temas aprendidos

### Tema 1: Estructura semántica de HTML5

**Definición con mis palabras:** HTML5 permite estructurar el contenido de una página web mediante elementos que representan su función, como encabezados, navegación, secciones y pie de página.

**Procedimiento:**

1. Organicé la estructura básica del documento HTML.
2. Identifiqué elementos semánticos y atributos como `lang`, `viewport` y `data-*`.
3. Revisé la función de las etiquetas meta relacionadas con la descripción de la página y el SEO.

**Conceptos clave:** HTML5, DOM, etiquetas semánticas, atributos, metadatos y SEO.

### Tema 2: Maquetación y diseño responsivo

**Definición con mis palabras:** CSS permite definir la presentación de una página, mientras que Flexbox y Grid ayudan a distribuir sus elementos. El diseño responsivo adapta la interfaz a distintos tamaños de pantalla.

**Procedimiento:**

1. Enlacé la hoja de estilos con el documento HTML.
2. Revisé la distribución de elementos con Flexbox y CSS Grid.
3. Analicé el uso de unidades relativas y funciones como `clamp()` y `calc()` para adaptar tamaños y espacios.

**Conceptos clave:** CSS3, Flexbox, Grid, media queries, tipografía fluida y diseño responsivo.

## Ejercicios de laboratorio y resultados

### Ejercicio 1: Construcción de una estructura HTML

**Objetivo:** Organizar el contenido de una página utilizando una estructura clara y semántica.

**Procedimiento:** Definí la estructura del documento, revisé sus metadatos y organicé los elementos de contenido y presentación.

**Resultado:** Establecí una base HTML sobre la que se puede aplicar el diseño visual mediante CSS.

### Ejercicio 2: Maquetación adaptable

**Objetivo:** Distribuir los elementos de la interfaz y facilitar su visualización en diferentes dispositivos.

**Procedimiento:** Revisé la aplicación de Flexbox y Grid, así como las propiedades y unidades que permiten adaptar el diseño.

**Resultado:** Comprendí cómo estructurar una interfaz y qué técnicas utilizar para hacerla responsiva.

## Reflexión semanal

- **¿Qué aprendí?** Aprendí a estructurar páginas con HTML5 y a utilizar CSS para organizar los elementos y adaptar la presentación a distintos tamaños de pantalla.
- **¿Cómo aprendí?** Mediante la práctica de maquetación, la revisión de propiedades CSS y el análisis de herramientas de validación.
- **¿Qué necesito reforzar?** Necesito practicar más las combinaciones de Grid y Flexbox, así como comprobar la accesibilidad y la visualización de mis páginas en distintos navegadores.
