# Semana 4 — JavaScript, manipulación del DOM y animaciones

Repositorio relacionado: [practica-semana-04-catch-ball](https://github.com/KatyTorres-web/practica-semana-04-catch-ball).

La guía de la semana 4 aborda JavaScript moderno, manipulación del DOM, funciones flecha, IIFE, closures y animaciones con Canvas API.

**Fecha o tema principal:** JavaScript moderno, manipulación del DOM, funciones avanzadas y Canvas API.

## Temas aprendidos

### Tema 1: JavaScript y manipulación del DOM

**Definición con mis palabras:** JavaScript permite incorporar comportamiento e interactividad a una página web. Mediante el DOM se pueden acceder a los elementos HTML y modificar su contenido, estructura o apariencia.

**Procedimiento:**

1. Organicé el documento HTML y el archivo JavaScript.
2. Revisé cómo seleccionar elementos y responder a eventos.
3. Analicé el uso de estructuras de control y funciones flecha para organizar la lógica.

**Conceptos clave:** JavaScript ES6+, DOM, eventos, funciones flecha y manipulación de elementos.

### Tema 2: Funciones avanzadas y animaciones

**Definición con mis palabras:** Las funciones IIFE permiten ejecutar una función inmediatamente, mientras que los closures permiten conservar acceso a variables de un contexto externo. Canvas API facilita la creación de gráficos y animaciones mediante código.

**Procedimiento:**

1. Revisé el uso de funciones IIFE y closures.
2. Analicé el ciclo de actualización de una animación.
3. Estudié el uso de Canvas API y `requestAnimationFrame()` para gestionar animaciones.

**Conceptos clave:** IIFE, closures, Canvas API, Event Loop y `requestAnimationFrame()`.

## Ejercicios de laboratorio y resultados

### Ejercicio 1: Desarrollo de Catch Ball

**Objetivo:** Aplicar JavaScript para crear una experiencia interactiva y comprender el funcionamiento de las animaciones.

**Procedimiento:** Organicé los archivos de la práctica y revisé el uso de eventos, funciones y técnicas de animación mediante Canvas API.

**Resultado:** La práctica se orientó a aplicar los fundamentos de JavaScript en una actividad interactiva y a comprender la actualización gráfica de elementos.

**Problemas y solución:** Durante la implementación, los errores deben identificarse revisando la consola del navegador y verificando la selección de elementos, los eventos y el ciclo de animación.

## Reflexión semanal

- **¿Qué aprendí?** Aprendí que JavaScript permite transformar una página estática en una interfaz interactiva y que el DOM facilita la modificación dinámica del contenido.
- **¿Cómo aprendí?** Mediante la revisión de ejemplos de código, el uso de funciones modernas y la práctica de animaciones.
- **¿Qué necesito reforzar?** Necesito practicar el manejo de eventos y el control de las animaciones para comprender mejor su ejecución y evitar actualizaciones innecesarias.
